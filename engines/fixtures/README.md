# Fixtures

`kg_floor_plan.py` is the KG building traced from the supplied raster drawing:
28 rooms with their types, plus doors and windows. It is **source**, not output
— it encodes a reading of a drawing and cannot be regenerated by running
anything. Its own docstring records that the drawing's west and east vertical
chains disagree by 2.16 m and which one was used.

`build_kg_scene.py` runs the real `cad.*` tools over it and writes
`out/walkthrough/kg.json` for the viewer.

Replace this with a client DXF and none of it is needed: the tools read a DXF
directly. It exists because no client drawing has been supplied.
